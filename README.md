# NIYANTRAN-PROTOTYPE-PHASE-SUBMISSION
A futuristic smart-grid prototype visualizing how AI can coordinate EV charging across Bengaluru to reduce overloads, stabilize feeder demand, and transform electric vehicles into a distributed energy resource. This repository contains the project website, animations, and concept demonstration.
## Running the Prototype

To run the visualization:

1. Open the website hosted from this repository.
2. Either:

   * Generate a new `.json` output using the `niyantran_core.py` Google Colab notebook, or
   * Use one of the sample `.json` files provided in the repository.
3. On the website, click **Load JSON** and upload the file.
4. The dashboard and animations will automatically visualize the simulation results.
